# Sahayak-AI

*Sahayak* means "helper" in Hindi. Sahayak-AI is a cognitive assistance and caregiver-support platform for elderly people living with dementia, designed with the North Eastern Region (NER) of India in mind. It is available as a web application and a mobile app.

## Problem

Dementia care in NER is held back by few specialists, patchy internet connectivity, language and cultural diversity, and heavy dependence on family caregivers who have little tooling. Most existing cognitive-training apps are English-only, generic, and not built for elderly users or low-connectivity settings.

## Solution

Sahayak-AI offers personalized daily cognitive activities, memory support, and progress tracking for patients, and gives caregivers clear insight into how their loved one is doing. It does **not** diagnose dementia. It is a cognitive assistance and monitoring tool that supports patients and caregivers alongside professional medical care.

## Key Features

**For patients**
- Adaptive cognitive games: memory, attention, pattern, and recall games whose difficulty adjusts to the patient's performance over time
- AI personalization: activities tuned to each patient's ability level, preferences, and engagement
- Memory assistance: reminders for medication, routines, appointments, and familiar people and places
- Voice-based interaction: hands-free use for users who struggle with typing or small screens
- Multilingual support: regional language options for NER's linguistic diversity
- Simple, elderly-friendly UI: large buttons, high contrast, minimal steps

For caregivers
- Caregiver dashboard: a view of the patient's activity, engagement, and cognitive performance trends
- Progress monitoring: performance tracked over time, with alerts for notable changes
- Shareable reports: summaries that can be taken to a doctor for informed discussions

## Tech Stack

- Frontend: React (web), with a mobile app version
- Flow: Landing page → Login → Patient dashboard → Games → Caregiver panel
- AI/ML: Python-based models for personalization, difficulty adaptation, and performance analysis

## Design Principles

- Responsible AI: no independent diagnosis; clearly framed as assistance and monitoring
- Privacy first: sensitive health and usage data handled with consent and minimal collection
- Culturally aware: content, language, and imagery relevant to NER communities
- Connectivity-aware: designed to remain usable on limited or unstable networks

## Impact

- Gives dementia patients engaging, accessible daily cognitive stimulation
- Reduces caregiver burden with monitoring and support
- Narrows the care gap in underserved, remote regions of NER
